Advanced AI Instruction Following and Conflict Resolution

Project Overview

This project demonstrates practical skills in evaluating AI responses when user instructions are conflicting, ambiguous, or contain multiple requirements.

It focuses on identifying instruction conflicts, assessing compliance, separating factual accuracy from instruction following, and ranking AI responses based on evaluation criteria.

Skills Demonstrated

* Identifying conflicting instructions
* Recognizing ambiguous prompts
* Evaluating instruction compliance
* Assessing factual accuracy independently
* Identifying absolute and unsupported claims
* Comparing and ranking AI-generated responses
* Writing constructive evaluator feedback

Practical Exercises

1. Conflicting Instructions: Compared responses to a prompt requesting exactly three bullet points and five paragraphs.
2. Multiple Instruction Requirements: Evaluated whether an AI response followed word limits, audience requirements, and scientific terminology instructions.
3. Instruction Following and Factual Accuracy: Identified a factual error in an explanation of photosynthesis and assessed its compliance with user instructions.
4. Comparative Response Ranking: Compared two exercise explanations using accuracy, relevance, completeness, clarity, and instruction-following criteria.

Evaluation Approach

Each exercise involved:

* Identifying the user’s individual requirements.
* Checking whether the instructions were compatible.
* Evaluating each requirement independently.
* Separating factual accuracy from instruction compliance.
* Identifying errors and missing requirements.
* Providing specific feedback and ranking responses.

Key Learning Outcomes

This project strengthened my ability to recognize instruction conflicts, evaluate complex prompts, distinguish factual errors from instruction-following failures, and provide clear explanations when ranking AI-generated responses.

Project Note

All exercises in this repository are educational simulations created for AI evaluation practice. They are not presented as professional client work.
